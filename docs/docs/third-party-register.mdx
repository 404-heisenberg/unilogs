# Third-Party Register

This is the single source of truth for every external dependency UniLogs
relies on: npm packages, third-party APIs and hosted services. The group
report and the course's *Tools* rubric line can cite this page instead of
repeating the list.

**How the licences were verified.** The table below is generated from the
two `package.json` files in this repository (`backend/` and `frontend/`, plus
the root and `docs/`), with the licence field read from each package's own
`package.json` as installed in `node_modules`. Versions are the resolved
versions at the time of writing (11 October 2026). API keys and OAuth secrets
never reach the browser — every external call happens server-side.

## External APIs

| API | What UniLogs sends | Scope | Terms |
| --- | --- | --- | --- |
| Google Calendar API | Calendar read requests from the backend | Read-only (`calendar.readonly`), user's chosen calendars | [Google API Terms](https://developers.google.com/terms) |
| Google OAuth 2.0 | Consent redirect for "Sign in with Google" and calendar access | Sign-in scopes plus the calendar scope when connecting | [Google API Terms](https://developers.google.com/terms) |
| SendGrid Mail API | Verification codes, password reset links, reminder digests | Recipient email address and message body | [SendGrid Terms](https://www.twilio.com/legal/tos) |

All three are called from the backend so no API key or token is ever exposed
in the browser. See [Tech Stack → External APIs](/tech-stack#external-apis).

## Accepted security advisories

Two dependency advisories are **accepted deliberately** rather than fixed,
because the fixes require breaking upgrades of non-shipping tooling:

- **Docusaurus build tooling** (`docs/`): development-only vulnerabilities in
  the docs build; fixes require breaking major-version upgrades.
- **`deepmerge-ts`** (reached through `@prisma/config`, the Prisma CLI):
  development-only, parses only our own configuration; the fix downgrades
  Prisma across a major version.

Neither advisory affects shipped runtime code. See the repository
`AGENTS.md` for the full reasoning.
