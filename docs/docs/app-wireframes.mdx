# Application Wireframes

Low-fidelity wireframes for UniLogs' core application screens, covering the flow
from the public landing page through to logging an entry against a project. For
the sign up, sign in and password reset screens, see
[Authentication Wireframes](./design.mdx).

The main navigation sidebar is collapsible. Each screen below is shown in both
its **expanded** state (icons with text labels) and its **collapsed** state
(icons only), since either may be the default depending on viewport width.

---

## Landing page

The public entry point for signed-out visitors: a short product description, a
"Getting started" call to action, and sign in / sign up links.
