# Authentication UI Wireframes

This document outlines the low-fidelity user interface wireframes for the **UniLogs** authentication module, covering Desktop and Mobile viewports.

---

## 1. Registration (Sign Up)

### Desktop
![Register Desktop Wireframe](@site/static/Register-Desktop.png)

The desktop sign-up interface includes form fields for user registration (Full Name, Email Address, and Password) alongside integrated **OAuth 2.0** third-party authentication options.

### Mobile
![Register Mobile Wireframe](@site/static/Register-mobile.png)

The mobile adaptation of the registration interface retains all desktop capabilities, tailored for touch targets and smaller screens.

---

## 2. Login

### Desktop
![Login Desktop Wireframe](@site/static/login-Desktop.png)

The desktop login interface features user credential entry (Email and Password) along with seamless **OAuth 2.0** single sign-on buttons.

### Mobile
![Login Mobile Wireframe](@site/static/login-mobile.png)

The mobile login interface mirror of the desktop design optimized for single-column mobile viewports.

---

## 3. Password Reset

### Desktop
![Password Reset Desktop Wireframe](@site/static/ResetPassword-Desktop.png)

The password recovery interface allows users to submit their registered email address to receive a secure password reset link.

### Mobile
![Password Reset Mobile Wireframe](@site/static/ResetPassword-mobile.png)

The mobile view for the password reset workflow, maintaining consistent input logic and action buttons.
