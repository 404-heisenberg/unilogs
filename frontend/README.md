# UniLogs — Frontend

React, TypeScript and Vite. Talks to the backend API.

## Getting started

```bash
npm install
cp .env.example .env
npm run dev
```

Runs on `http://localhost:5173`. Set `VITE_API_URL` in `.env` to point at your
local backend, normally `http://localhost:3000`.

## Scripts

| Command            | Does                               |
| ------------------ | ---------------------------------- |
| `npm run dev`      | Development server with hot reload |
| `npm run build`    | Production build into `dist/`      |
| `npm run preview`  | Serve the production build locally |
| `npm run lint`     | ESLint                             |
| `npx tsc --noEmit` | Type check without emitting        |

Run all of `tsc --noEmit`, `lint` and `build` before opening a pull request.

## Stack

| Concern      | Library           |
| ------------ | ----------------- |
| Routing      | React Router      |
| Client state | Zustand           |
| Server state | TanStack Query    |
| Styling      | Tailwind CSS v4   |
| Components   | shadcn/ui (Radix) |
| Charts       | Recharts          |

TanStack Query handles anything that comes from the API — caching, loading and
error states. Zustand is for state that never touches the server, such as UI
preferences. Do not store API responses in Zustand.

## Conventions

Imports use the `@/` alias, which points at `src/`:

```ts
import { Button } from '@/components/ui/button';
```

The alias is configured in `vite.config.ts` and in both tsconfig files. Note that
`baseUrl` is deliberately absent — it is deprecated and stops working in
TypeScript 7.0. The alias resolves from `paths` alone.

## `src/components/ui/`

Generated by shadcn/ui. Add components with:

```bash
npx shadcn@latest add <component>
```

This folder is excluded from ESLint and Prettier. The generator overwrites it on
update, and its export pattern conflicts with the `react-refresh/only-export-components`
rule. Do not edit these files by hand — your changes will be lost.
